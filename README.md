# Wildlife Activity Monitoring & Alert Generation

A Hybrid CNN + LSTM deep learning system that detects animal species
and monitors abnormal wildlife activity in real time.

## Accuracy
96% detection accuracy on real-world wildlife dataset

## Tech Stack
Python | Django | TensorFlow | OpenCV | CNN | LSTM | SQLite

## Features
- Real-time wildlife activity detection
- Hybrid DNN model combining CNN + LSTM
- Automated alert generation system
- Web interface built with Django

## How to Run
pip install -r requirements.txt
python manage.py runserver
